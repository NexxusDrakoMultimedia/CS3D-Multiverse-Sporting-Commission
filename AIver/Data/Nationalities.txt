# Multiverse Sporting Commission - country identity aggregation.
#  Created by Nexxus Drako, with Claude's assistance.
#
# A section does not make a country playable. Only !Country or
# !AdditionalCountry in a selected League/international* dataset activates
# national-team, calendar and competition behavior. Paired files under
# Data/Names merely allow an otherwise inactive country to represent imported
# player nationalities as a reference country.
#
# Every MSC nation draws on the shared Multiverse name pool, so 'names' is
# Multiverse throughout - Multiverse_1st.txt / Multiverse_2nd.txt.
#
# Repeating alias is intentional. Matching is exact apart from surrounding
# whitespace and case. Repeating rewrite replaces that standalone phrase with
# display only in user-visible country and competition labels.
#
#
#  REGION TAXONOMY
#
#  Fourteen regions, grouped into four macro-regions:
#
#    Itavrnai Union               itavrnai, vyktoria, new-rythorn
#    New Bradmanian Commonwealth  new-bradman, ryukawa, castolo
#    Cyberya                      layns-wyred, determi, nexxie, jarokn
#    Galatyan                     mancunya, wyrmwoode, centralya, esmeraldys
#
#  Ten nations are unregioned and belong to no bloc. Region slugs are what
#  the scouting providers address with Home region / Allowed region; the
#  unregioned ten are reachable by nation only.
#
